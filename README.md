Projects :

✅ Task 1 – To-Do List

A simple command-line To-Do List application that allows users to manage their daily tasks.

Features :
- ➕ Add new tasks
- 🗑️ Delete tasks
- 📋 Display all tasks
- 🔄 Menu-driven interface
- 💻 Simple and beginner-friendly design

Concepts Used :
- Python Lists
- Loops (`while`)
- Conditional Statements (`if`, `elif`, `else`)
- User Input (`input()`)

✅ Task 2 – Expense Tracker

A command-line Expense Tracker that allows users to enter expenses and calculates the total amount spent.

Features :
- 💰 Add multiple expenses
- ➕ Automatically calculate the total expense
- 🛑 Stop the program using `0`
- ⚠️ Handles invalid input using `try-except`
- 🚫 Prevents negative expense values
- 📊 Displays the number of valid expenses entered

Concepts Used :
- Variables
- While Loops
- Conditional Statements
- Exception Handling (`try-except`)
- Accumulator Logic
- User Input
- Mathematical Operators
